# Проверка договора

## 0. Перед началом
- Чья сторона? Ты проверяешь в интересах клиента - продавца, покупателя, исполнителя, заказчика. От этого зависят все оценки.
- Какая цель сделки и что для клиента критично: деньги, сроки, качество, возможность выйти из договора?
- Это B2C (с потребителем) или B2B? Для B2C - обязательно скилл `zashchita-potrebiteley`.
- Если договор про рассрочку - дополнительно скилл `islamskaya-rassrochka`.

## 1. Квалификация
Определи тип договора по существу, а не по названию (купля-продажа, поставка, услуги, подряд, агентский, комиссия, заём, аренда, лицензионный, смешанный - ст. 421 п. 3 ГК). Найди специальные нормы ГК для этого типа.

## 2. Существенные условия (без них договор не заключён - ст. 432 ГК)
- Предмет - всегда.
- Условия, названные существенными в законе для этого типа (напр., для купли-продажи - наименование и количество товара; для рассрочки - цена, порядок, сроки и размеры платежей, ст. 489 ГК; для аренды недвижимости - объект; для подряда - сроки начала и окончания).
- Условия, по которым одна из сторон потребовала согласовать.

## 3. Чек-лист по разделам

| Раздел | Что проверить |
|---|---|
| Стороны | Полные наименования, ИНН/ОГРН, полномочия подписанта (устав, доверенность), проверка контрагента по ЕГРЮЛ/ЕГРИП, не в стадии ликвидации/банкротства (`egrul.nalog.ru`, `fedresurs.ru`, `kad.arbitr.ru`) |
| Предмет | Однозначно ли, можно ли идентифицировать товар/результат |
| Цена и оплата | Цена фиксирована или формула; НДС включён/не облагается; сроки оплаты; что считается датой оплаты; предоплата и её возврат |
| Сроки | Начало, окончание, промежуточные; что при просрочке |
| Передача и приёмка | Акт, УПД, сроки приёмки, мотивированный отказ, переход права собственности и риска случайной гибели (ст. 211, 223, 459 ГК) |
| Качество и гарантия | Стандарты, гарантийный срок, порядок претензий |
| Ответственность | Неустойка (размер, база, предел), ограничение ответственности (нельзя ограничить за умысел - ст. 401 п. 4 ГК), убытки |
| Расторжение | Односторонний отказ (ст. 450.1 ГК), основания, уведомление, расчёты при выходе |
| Форс-мажор | Ст. 401 п. 3 ГК, порядок уведомления, подтверждающие документы |
| Конфиденциальность и ПД | Передаются ли персданные - нужна ли поручение на обработку (ст. 6 ч. 3 152-ФЗ) |
| ИС | Кому принадлежат результаты; лицензия или отчуждение; указан ли способ использования и территория (ст. 1235, 1270 ГК) |
| Споры | Претензионный порядок и срок ответа; подсудность (для потребителя - нельзя лишить права выбора суда, ст. 17 ЗоЗПП); третейская оговорка |
| Уведомления | Адреса, e-mail, мессенджеры как юридически значимые каналы (ст. 165.1 ГК) |
| Подписание | Форма (письменная, ЭДО, ПЭП), количество экземпляров, приложения подписаны |

## 4. Красные флаги
- Односторонний отказ/изменение условий только для одной стороны без компенсации.
- Неустойка без предела или с несоразмерной базой (будет снижена судом по ст. 333 ГК, но спор неизбежен).
- Предоплата 100% без обеспечения и без срока возврата.
- Автоматическая пролонгация с неудобным сроком отказа.
- Переход права собственности раньше оплаты при отсутствии залога (для продавца) - или наоборот.
- «Акт считается подписанным, если не возражали в течение 1 дня».
- Скрытые платежи, комиссии, курсовые оговорки.
- Для потребителя: условия, ущемляющие права (ст. 16 ЗоЗПП) - ничтожны и штрафуются.
- Для шариатской модели: проценты за просрочку (ст. 395 ГК применяется по умолчанию - нужно прямо исключить), плата за время/отсрочку, продажа товара, которым продавец ещё не владеет.

## 5. Результат

```
## Вывод
Можно подписывать / можно после правок / нельзя - и почему (2-3 предложения).

## Критичные риски
| № | Пункт | Проблема | Риск | Правка |

## Важные замечания
...

## Мелкие правки и редактура
...

## Чего не хватает в договоре
...

## Вопросы к клиенту
...
```

Правки - готовым текстом пункта («Изложить п. 5.2 в редакции: "..."»), чтобы можно было вставить в протокол разногласий. Если нужен сам протокол - таблица «Редакция контрагента | Редакция клиента | Обоснование».

Если договор в .docx и нужен режим правок - используй скилл `anthropic-skills:docx` (tracked changes).
