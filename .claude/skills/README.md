# Скиллы для видео автора (@ramin.abakov)

Две серии разных жанров — у каждой свой сценарный скилл, свои законы и свой формат.

| Скилл | Для чего |
|---|---|
| `viral-video-dna` | Старт: выбор серии, законы жанров, два раздельных разбора по 5 роликов, герои |
| `script-bez-stuka` | Сценарии серии А — вертикальная семейная драма «без стука» |
| `script-ai-creator` | Сценарии серии Б — горизонтальная притча «Наставник и Ученик» (курс AI Creator) |
| `shotlist-ai-video` | Раскадровка и промпты для генерации клипов (раздельно для А и Б) |
| `edit-subtitles-endcard` | Монтаж: субтитры, финальные карточки, звук — `scripts/render_video.py` |
| `viral-packaging` | Подпись, хук, хэштеги, воронка, A/B, пометка AI |
| `video-panel-review` | Панель экспертов: оценка перед публикацией |

Порядок работы: `viral-video-dna` → сценарий → `shotlist-ai-video` → `edit-subtitles-endcard` → `viral-packaging` → `video-panel-review`.

Чтобы использовать скиллы в других проектах, скопируй папки в `~/.claude/skills/`.
