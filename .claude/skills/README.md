# Юридические скиллы RIZQ

Набор навыков для Claude Code: «юрист» по праву РФ с учётом исламской модели бизнеса.
Агент-юрист: `.claude/agents/yurist.md`. Скиллы подхватываются автоматически по описанию или вызываются по имени (`/islamskaya-rassrochka`).

| Скилл | Для чего |
|---|---|
| `yuridicheskiy-analiz` | Базовый метод: факты → квалификация → нормы → риски → ответ. Профиль проекта - `profil-biznesa.md` |
| `poisk-zakonodatelstva` | Где и как искать нормы и практику, проверка редакций, цитирование |
| `proverka-dogovora` | Проверка договора, риски, правки, протокол разногласий |
| `sostavlenie-dogovora` | Составление договоров с нуля |
| `islamskaya-rassrochka` | Мурабаха по праву РФ: ГК, риск «заём», ЗоЗПП, касса, партнёры, вопросы шариатскому совету |
| `personalnye-dannye` | 152-ФЗ: согласия, политика, РКН, локализация, cookies |
| `zashchita-potrebiteley` | ЗоЗПП: информация, возврат, сроки, недопустимые условия |
| `reklama` | 38-ФЗ: маркировка, реклама рассрочки, площадки, рассылки |
| `intellektualnaya-sobstvennost` | Переводы, аудио, фото, шрифты, договоры с авторами, товарный знак |
| `religioznyy-kontent` | 125-ФЗ, экстремистские списки, иноагенты, 436-ФЗ |
| `dokumenty-sayta` | Оферта, пользовательское соглашение, реквизиты, авторизация |
| `blagotvoritelnost` | Садака и сборы: модели, налоги, 115-ФЗ |
| `nalogi-i-biznes` | ИП/ООО, УСН/НПД/НДС, ККТ, банки, финансирование бизнеса |
| `trudovye-otnosheniya` | Трудовой договор vs ГПХ, самозанятые, намаз и праздники, дети |
| `semeynoe-pravo` | Имущество супругов, брачный договор, раздел, алименты, имущество детей |
| `pretenzii-i-sudy` | Претензии, давность, подсудность, приказ, доказательства, исполнение |
| `yuridicheskoe-pismo` | Письма, ответы госорганам и банкам, доверенности |
| `pravovoy-audit` | Полный аудит проекта и план устранения рисков |

Важно: скиллы помогают в работе, но не заменяют очную консультацию юриста или адвоката по крупным сделкам и спорам. Нормы, помеченные «проверить», сверяйте с действующей редакцией.
