# Панель экспертов: ревью ролика

Роли «играет» один агент — последовательно, каждая со своим фильтром. Сначала **определи серию** (иначе рубрики не те): вертикаль 9:16 с окном 4:3 и дуэтом совести → А; горизонталь с Наставником и Учеником → Б. Если неясно — спроси. Законы — `viral-video-dna`.

## Вход
Любое из: сценарий, таблица планов, ссылка/файл ролика (кадры + субтитры), статистика. Если ролик есть, посмотри **кадры по 1/с** и прочитай субтитры; громкость/ритм можно измерить `ffmpeg`. Чего не видишь/не слышишь — **так и пиши** («звук не проверял»), не выдумывай.

## Рубрика (каждый пункт 0–2: 0 нет, 1 слабо, 2 сильно)

### Серия А — «без стука» (17 пунктов, max 34)
| Эксперт | Пункты |
|---|---|
| Продюсер | П1 тема из «семейных болей» и узнаваема за 3 с · П2 призыв «отправь/скажи сегодня» в конце · П3 соблюдён формат (окно 4:3, плашка, шрифт) |
| Драматург | Д1 хук-реплика ≤ 6 слов · Д2 первый вывод зрителя ошибочен · Д3 переворот к 40–60 % · Д4 подтекст проговорён · Д5 ≤ 4 улик с правдоподобными цифрами |
| Режиссёр | Р1 слом: слёзы 3–5 с, игра микродвижениями · Р2 финальный двойной кадр и взгляд в камеру |
| Оператор | О1 свет-территория (тёплое/холодное/неон), лица крупно · О2 макро-улика |
| Монтажёр | М1 ритм 1,8–3 с, пик держится · М2 субтитры не закрывают лица, ≤ 2 строк |
| Звук | З1 подложка непрерывна, затухание в тишину на плашке |
| Growth | G1 максима ≤ 9 слов, цитируема · G2 нет морализаторства > 40 % |

### Серия Б — «Наставник и Ученик» (16 пунктов, max 32)
| Эксперт | Пункты |
|---|---|
| Продюсер | П1 одно возражение клиента — один ролик · П2 карточка курса без цены/обещаний · П3 мягкий оффер внутри сюжета (≤ 1 раза) |
| Драматург | Д1 хук-аномалия ≤ 3 с · Д2 Ученик озвучил возражение, Наставник показал образ (а не лекция) · Д3 «Я тоже так делал» · Д4 афоризм ≤ 9 слов, работает без курса |
| Режиссёр | Р1 физическое действие Ученика на финале · Р2 петля к стартовому образу |
| Оператор | О1 золотой час и масштаб «маленький человек» · О2 метафора выглядит осязаемо |
| Монтажёр | М1 акцентный стек по слову, сбоку от лица · М2 ритм 1,4–3,7 с, VFX-момент не зарезан |
| Звук | З1 подложка + спад перед афоризмом, тишина на карточке |
| Growth | G1 афоризм = заголовок поста · G2 возражение узнаваемо за 3 с |

## Процесс
1. Определи серию, проверь формат (пропорции, шрифт, плашка/карточка).
2. Пройди рубрику по ролям. **По каждому пункту — доказательство** (таймкод/реплика/кадр), без доказательства оценка не ставится.
3. Найди **три главные правки**, которые поднимут больше всего (приоритет: хук → переворот/метафора → финал).
4. Отметь **риски:** шаблонность, морализаторство, ошибки культуры/цифр, права на музыку/лица, пометка AI, обещания дохода.
5. Вердикт: **≥ 85 % баллов и нет «0» в хуке/перевороте/финале — публиковать · 60–84 % — доработать · < 60 % или «0» в хуке — переделать.** (Пороги — рабочая эвристика, не закон; пересмотри по статистике.)

## Анти-паттерны ревью
- Не хвали без доказательства; не критикуй «вообще».
- Не предлагай приёмы чужой серии (слёзы и цифры — в Б, VFX-метафоры — в А).
- Не переписывай весь сценарий: давай **точечные замены** (реплика → реплика, кадр → кадр).
- Не называй причины просмотров фактами — это гипотезы, пока нет метрик.
