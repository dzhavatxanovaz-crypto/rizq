# Сценарий серии «Наставник и Ученик» (AI Creator)

Жанр: **притча-реклама**. Законы — в `viral-video-dna` (раздел «Законы серии Б»), разбор 5 роликов — `viral-video-dna/references/analysis-ai-creator.md`. Герои и внешность — `viral-video-dna/references/characters.md`.

**Это не серия А.** Здесь нет «суда совести», цифр-улик и слёз по бытовому поводу; есть **метафора, которую можно потрогать**.

## Вход
1. **Возражение клиента**, которое снимаем (одна фраза). Примеры: «у меня нет идей», «это для технарей», «я уже старый для этого», «нет времени», «а вдруг у меня не получится».
2. **Хронометраж:** 65 с (динамичный) · 80 с (рефлексия).
3. **Оффер/дата старта** (если есть): «СТАРТ …» — отдельная сменная карточка; если нет — без даты.
4. Город/локация (по умолчанию — старый европейский квартал, золотой час).

## Алгоритм

1. **Возражение → страх → объект.** Переведи абстракцию в **физический предмет или пространство**, которое можно изменить:
   | Страх | Объект | Действие Ученика |
   |---|---|---|
   | «Это не для меня» | стеклянный колпак | бьёт стекло → пыль |
   | «Все уже впереди» | линейка-дверь с зарубками, уменьшение тела | снимает капюшон, выпрямляется |
   | «У меня всё стабильно» | колея-траншея в брусчатке | сворачивает в проулок |
   | «Начну завтра» | песок из подошвы, статуи-толпа, мох на ботинке | вытряхивает песок, делает шаг |
   | «Идея сырая» | голограмма мотоцикла, свалка, игрушка «вес идеи» | катит игрушку пальцем |
   Новая метафора = **материал + симптом + способ освободиться** (напр. «Я подожду, пока будет время» → песочные часы, засыпающие обувь; освобождение — опрокинуть часы).
2. **Хук (0–3 с)** — аномалия без слов: крупный план объекта + необычное действие среды. Должна быть интригой «что это?»
3. **Диалог «вопрос → образ»:** Наставник и Ученик идут. Ученик озвучивает возражение **первой репликой своей линии**. Наставник отвечает **образом/показом**, не лекцией.
4. **Пик (35–60 %):** Ученик плачет/осознаёт — крупный план 3–4 с. Наставник признаёт: «Я тоже так делал».
5. **Действие (65–85 %):** Ученик делает физический жест — метафора разрушается/меняется (VFX-момент, 3–5 с).
6. **Петля:** в финале возвращайся к стартовому образу (человек в колпаке остался; толстяк в кафе).
7. **Афоризм** (≤ 9 слов, самодостаточный, формулой «Х — это Y» / «Между X и Y — Z» / «Один Х отделяет…»).
8. **Карточка курса** (без цены и обещаний): `КУРС ОБУЧЕНИЯ НЕЙРОСЕТЯМ` / `· AI CREATOR ·` / `подробности в директ`. Дата — отдельный кадр, если нужна.

## Структура 65–85 с

| Время | Бит |
|---|---|
| 0–3 | аномалия-метафора, 1 субтитр-интрига (≤ 5 слов) |
| 3–12 | выход Наставника и Ученика, постановка темы |
| 12–30 | возражение Ученика, неудачная попытка, насмешка/катализатор (друг со смартфоном) |
| 30–55 | демонстрация: Наставник показывает метафору; крупные планы; признание «я тоже» |
| 50–62 | слом: слёзы/озарение Ученика |
| 58–75 | действие-трансформация + масштабный кадр сверху |
| 75–80 | возврат к стартовому образу |
| +3 | афоризм на чёрном |
| +3 | карточка курса |

## Правила диалога и субтитров

- Реплики ≤ 8 слов, дробятся на 2-словные «чанки» (акцентный стек: последнее слово крупное). Ритм речи ≈ 2,5–3 слова/с.
- Наставник говорит **утверждениями-образами** («Каждая железка тут была гениальной — пока не проверили»), Ученик — **коротко и честно** («Я в этом не разбираюсь»).
- Мягкий оффер внутри сюжета — устами друга: «Хочешь, научу сам нейросетями?» (не более 1 раза).
- Никаких обещаний дохода, сроков «за 7 дней», «гарантируем». Не пугать, а снимать страх.
- Афоризм не должен содержать названия курса.

## Банк афоризмов-образцов (не копировать, а переосмысливать)

- Между идеей и результатом — только страх.
- «Это не для меня» — самый тихий способ сдаться.
- Чужая жизнь — не линейка.
- Тысяча одинаковых дней — это один день.
- Один шаг отделяет тебя от тех, кто стоит.

Новые заготовки: «Совершенство — это просто страх, переодетый в перфекционизм.» · «Нейросеть не заменит тебя — она заменит твои отговорки.» · «Первая версия всегда уродлива. Поэтому её никто не показывает.» · «Опоздать можно только туда, куда ты не идёшь.»

| Время | Кадр / действие | Реплика (чанки) | Сторона субтитра |
|---|---|---|---|
| 0:00–0:03 | макро: … | — | — |
| 0:03–0:08 | Наставник и Ученик идут… | «Самое страшное — он этого не замечает» | справа |

## Чек-лист перед сдачей

- [ ] Одно возражение — одна метафора — одно физическое действие
- [ ] Хук-аномалия ≤ 3 с, без текста или с ≤ 5 словами
- [ ] Ученик озвучивает возражение раньше, чем Наставник даёт образ
- [ ] Наставник признаёт «я тоже»
- [ ] Слёзы/озарение 3–4 с
- [ ] VFX-момент разрушения/изменения метафоры
- [ ] Афоризм ≤ 9 слов, работает без курса
- [ ] Карточка курса без цены/обещаний; дата — отдельным кадром
- [ ] Есть петля к стартовому образу
