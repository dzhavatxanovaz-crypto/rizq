# Монтаж, субтитры и финальные карточки

Монтажёр + звукорежиссёр. Вход — склеенный в монтажке клип (или клипы, склеенные по раскадровке) и JSON с репликами (его даёт `script-bez-stuka` / `script-ai-creator`). Выход — `final.mp4` + `.ass` рядом (его можно поправить и пересобрать).

**Серии разные — форматы разные.** Не смешивать.

## Скрипт `scripts/render_video.py`

Требует `ffmpeg` с libass и `ffprobe`. Python 3 без внешних библиотек.

```bash
# серия А
python3 .claude/skills/edit-subtitles-endcard/scripts/render_video.py \
  --format bez-stuka --video cut.mp4 --script ep01.json --out ep01.mp4 [--fonts-dir ./fonts] [--fit crop|pad]
# серия Б
python3 .claude/skills/edit-subtitles-endcard/scripts/render_video.py \
  --format ai-creator --video cut.mp4 --script ac01.json --out ac01.mp4 [--fonts-dir ./fonts]
# только субтитры (для правки таймингов в Aegisub/Subtitle Edit)
python3 … --format bez-stuka --video cut.mp4 --script ep01.json --ass-only
```

Что делает:
- **bez-stuka:** вписывает клип в окно 720×540 (4:3) по центру холста 720×1280 (`--fit crop` обрезает по центру, `pad` вписывает с полями), субтитры — одна/две строки белым жирным курсивом под окном (центр ≈ y=962), затухание 150 мс; после клипа 3 с чёрного с плашкой (по умолчанию «@handle» — задай в JSON).
- **ai-creator:** кадр 1280×720; реплики режутся на чанки по 1–2 слова, последнее слово крупное и яркое (64 pt), предыдущие мельче и тусклее (46 pt, ~55 % непрозрачности); сторона `right|left|center`, высота `y` (доля высоты, по умолчанию 0,74); в конце афоризм (капс, по центру, 2,8 с) → карточка курса (3 с).
- Звук: нормализация `loudnorm` −14 LUFS (отключается `--no-loudnorm`), затухание 0,5 с перед карточкой, тишина на карточке.
- Размер: H.264 CRF 18, AAC 192 кбит/с, 30 fps, `+faststart`.

Проверено: оба формата рендерятся на тестовом клипе, размеры 720×1280 и 1280×720, длина = клип + карточки.

### Шрифты (нужно поставить)
| Роль | Шрифт | Где взять |
|---|---|---|
| Серия А: субтитры и плашка | **Roboto Condensed Bold Italic** | Google Fonts (OFL) |
| Серия Б: акцентный стек, афоризм, «AI CREATOR» | **Bebas Neue** (или близкий узкий гротеск) | Google Fonts (OFL) |
| Серия Б: «подробности в директ» | **Montserrat Light/Regular** | Google Fonts (OFL) |

Положи `.ttf` в папку и передай `--fonts-dir`. Если шрифта нет, libass подставит системный — раскладка сохранится, но облик будет другим (проверь в предпросмотре). Шрифты в формате `.woff2` для libass не годятся — нужны `.ttf/.otf`.

### JSON-формат
См. `templates/bez-stuka.example.json` и `templates/ai-creator.example.json`.
- `lines[]`: `start`, `end` (секунды в итоговом клипе), `text`; для Б ещё `side`, `y`.
- `end_card`: А — `duration`, `lines:[{text,style}]` (`CardBig`/`CardSmall`); Б — `aphorism`, `aphorism_duration`, `kicker`, `brand`, `cta`, `duration`.
- `fonts`: переопределение названий шрифтов (`sub`, `card`, `light`).
- Дату старта для серии Б делай **отдельным** вариантом JSON/карточки — она устаревает.

## Ритм склейки

**Серия А (драма)**
- Средний план 1,8–3 с; на реплику — смена плана или реакция; **пик (слёзы) держи 3–5 с без смены**, перед ним 2–3 быстрые реакции.
- Только жёсткие склейки; переход в плашку — через чёрный (0,25 с).
- Субтитр появляется на 2–4 кадра раньше первого слова и уходит сразу после последнего; смена каждые 1,5–3 с; максимум 2 строки, ~90 символов; скорость чтения не выше ~15 символов/с.
- Реплики-обрывы (`сы… Удачи.`) — не «дочитывай» вторую часть сразу: оставь 0,3–0,5 с тишины.

**Серия Б (притча)**
- Средний план 1,4–3,7 с; быстрее на хуке/демонстрации, медленнее на рефлексии (ролик «Колея» ≈ 3,7 с).
- Субтитры «по слову» синхронизируй с речью (≈ 2,5–3 слова/с); не ставь чанк дольше 1,3 с.
- Блок субтитров **в негативном пространстве** (сбоку от лица, нижняя треть) — меняй сторону между планами; не закрывай глаза и рот.
- VFX-момент разрушения — не режь, держи 3–5 с в slow-motion.
- Финал: возврат к стартовому образу (1–2 плана) → чёрный → афоризм → карточка.

## Звук
- Подложка непрерывная, речь стабильно поверх; без «мёртвой» тишины внутри ролика. Громкость ≈ −14 LUFS итогового микса (скрипт нормализует).
- Подъём подложки **перед** максимой/афоризмом, затем затухание в тишину на карточке (2–3 с).
- Эффекты метафор (стекло, песок, шаги) — добавляй отдельными слоями в аудио-редакторе; скрипт не микширует.
- Музыка — только с лицензией (библиотека/свой материал); проверь права для рекламы курса.

## Безопасные зоны и экспорт
- Серия А: окно по центру оставляет сверху и снизу по ~29 % чёрного; интерфейс площадки (подпись, кнопки) попадает на поля и не закрывает лица. Текст не уезжает за 12 % от краёв.
- Серия Б: 16:9 для YouTube/сайта; в вертикальные ленты — отдельный монтаж (кроп по центру ломает «сторонние» субтитры — перекомпонуй).
- Экспорт: mp4 H.264, 30 fps, AAC, −14 LUFS; проверь на телефоне без звука.

## Чек-лист перед публикацией
- [ ] Читается без звука
- [ ] Субтитры не закрывают лица/глаза/рот
- [ ] Каждая реплика читается ≥ 1,5 с
- [ ] Финальная карточка 2–3 с, звук в тишину
- [ ] Шрифты применены (не системная подмена)
- [ ] Дата старта актуальна (или карточка без даты)
- [ ] Длина серии А ≤ 86 с, серии Б ≤ 86 с
