# ДНК вирусных роликов автора

Опорный скилл. Он ничего не рендерит — выбирает серию и задаёт законы. Остальные скиллы:
`script-bez-stuka` · `script-ai-creator` · `shotlist-ai-video` · `edit-subtitles-endcard` · `viral-packaging` · `video-panel-review`.

**Две серии — два разных жанра. Разобраны раздельно, законы не смешивать:**

| Разбор | Файл |
|---|---|
| Серия А, ролики 1–5 — семейная драма | `references/analysis-bez-stuka.md` |
| Серия Б, ролики 6–10 — притча-реклама курса | `references/analysis-ai-creator.md` |
| Герои и «библия внешности» (блоки для промптов) | `references/characters.md` |

> Метод разбора: просмотр по кадрам, чтение вшитых субтитров, измерение громкости и ритма (детектор смены планов). Речь не расшифровывалась, музыка не определялась. Причины вирусности — **гипотезы по содержанию**, без статистики просмотров. Проверяй их на метриках (см. `viral-packaging`).

## Выбор серии

| | **А. «без стука»** — семейная драма | **Б. «Наставник и Ученик»** — притча-реклама |
|---|---|---|
| Что это | «суд совести» над обычной семейной ссорой | диалог-притча, в которой страх зрителя становится физическим предметом |
| Формат | вертикаль 720×1280, кино-окно **4:3**, субтитры на чёрном под окном | горизонталь 16:9, на весь кадр |
| Длина | 36–86 с | 65–86 с |
| Герои | семья + дуэт совести (Красная куртка, Белая рубашка) | Наставник + Ученик (+ друг со смартфоном) |
| Эмоция | стыд → слёзы → примирение | страх → озарение → шаг |
| Двигатель | **переворот оценки** («он не хам — он боится не быть нужным») | **метафора-объект** (колпак, колея, линейка, песок, свалка) + физическое действие |
| Доказательство | цифры и улики (₸, чеки, подарок) | образ и демонстрация |
| Финал | максима ≤ 9 слов + взгляд в камеру «отправь это видео» + плашка `@ramin.abakov · без стука` | афоризм ≤ 9 слов на чёрном + карточка «КУРС ОБУЧЕНИЯ НЕЙРОСЕТЯМ · AI CREATOR · подробности в директ» |
| Цель | охват, пересылки, подписчики | заявки в директ |
| Свет | тёплые лампы + холодный ночной город; неон у подростка | золотой час, контровой, старые города |
| Субтитры | одна строка Roboto Condensed Bold Italic под окном | капс Bebas-типа по слову, «акцентный стек» сбоку от лица |
| Режим скилла | `script-bez-stuka` | `script-ai-creator` |

Правило выбора: **нужен охват и душевный отклик → А. Нужны заявки на курс → Б.** Если непонятно — спроси цель одним вопросом.

## Что действительно общее (3 принципа)

1. **Хук ≤ 2 с, понятен без звука.** А: самая грубая реплика конфликта. Б: визуальная аномалия.
2. **Один тезис — одна «улика».** А: 3–4 цифры/предмета. Б: одна метафора.
3. **Финальная фраза ≤ 9 слов + один призыв.** Без «лайк/подписывайся». Фраза должна работать без контекста (её цитируют).

Технически общее: субтитры вшиты всегда; непрерывная подложка и голос, на финале затухание в тишину; жёсткие склейки, без эффектов-переходов; финальная карточка 2–3 с на чёрном; средний план 1,4–3,7 с.

## Законы серии А (детали — `analysis-bez-stuka.md`)

1. Первые 15 с даём повод осудить героя; к 40–60 % хронометража — переворот (скрытая жертва/страх).
2. Подтекст проговаривает совесть вслух («Ты хотел сказать не это» → «Я боюсь, что больше тебе не нужен»).
3. Улики: ≤ 4, конкретные, с реальными суммами и валютой.
4. Слёзы мужского лица — 3–5 с без реплики.
5. Виноваты все понемногу, любят все — иначе не пересылают родителям/детям.
6. Финальный двойной кадр (два героя совести по центру) + взгляд в камеру.
7. Культурная специфика точная (₸, «балам», той, «сы…») — «это про мою семью».

## Законы серии Б (детали — `analysis-ai-creator.md`)

1. Аномалия-метафора в первые 3 с, почти без слов.
2. Ученик озвучивает возражение зрителя; Наставник не спорит — **показывает**.
3. Метафора физическая и обратимая; Ученик **делает действие** (бьёт стекло, вытряхивает песок, сворачивает с колеи).
4. Наставник эмпатичен («Я тоже так делал»), не высокомерен.
5. Один ролик — одно возражение покупателя курса (идея сырая / не для меня / сравнение / рутина / завтра).
6. Афоризм самодостаточен — работает без курса.
7. Петля: финал возвращается к стартовому образу.
8. Карточка курса без цены, ссылки и обещаний дохода; дату старта держать отдельным сменным шаблоном.

## Маршрут продюсера

1. Цель → серия (таблица выше).
2. Сценарий: А → `script-bez-stuka`; Б → `script-ai-creator`.
3. `shotlist-ai-video` — раскадровка и промпты для генерации (с «библией внешности»).
4. `edit-subtitles-endcard` — монтаж-финал (`scripts/render_video.py --format bez-stuka|ai-creator`).
5. `viral-packaging` — подпись, хэштеги, первый кадр, комментарий-приманка, пометка AI.
6. `video-panel-review` — панель экспертов оценивает сценарий/ролик перед публикацией.

## Быстрый чек-лист «это наш ролик?»

**Общий:** хук ≤ 2 с · читается без звука · фраза-финал ≤ 9 слов · один призыв · плашка/карточка 2–3 с · звук в тишину.
**А дополнительно:** ошибочный первый вывод · переворот · подтекст вслух · ≤ 4 улик · слёзы 3–5 с · двойной кадр · «отправь это видео».
**Б дополнительно:** метафора-объект · возражение Ученика · физическое действие · акцентный стек · афоризм + карточка курса · петля.

## Чего избегать

- Смешивать жанры: слёзы и цифры из А не нужны в Б; VFX-метафоры из Б не нужны в А (там реализм и быт).
- Морали в лоб в начале; злодеев в серии А; высокомерного Наставника в серии Б.
- Обещаний дохода и «гарантий результата» в рекламе курса.
- Реальных людей/узнаваемых лиц в сгенерированных сценах; ролики с реалистичным AI-контентом помечать по правилам площадки (см. `viral-packaging`).
